# Founders Meeting 004

Date: August 17, 2026

## Topic

Defining the Core Value of Project Spector

## Discussion

The team discussed what value Project Spector provides to paranormal production teams and content creators.

While many paranormal products focus on collecting evidence, Project Spector will focus on helping users review and understand evidence more efficiently.

The largest pain point identified is the amount of time required to review investigation footage, audio recordings, investigator notes, and sensor readings after an investigation.

## Decision #001

Project Spector's primary value proposition is time savings.

The platform will reduce the amount of time required to organize, synchronize, review, and analyze evidence collected during paranormal investigations.

## Decision #002

Project Spector's long-term vision is to become the operating system for paranormal productions.

However, the initial product will focus on evidence organization and timeline analysis.

## Core Product Concept

Project Spector will provide a unified investigation timeline.

Multiple evidence sources will be mapped simultaneously onto a single chronological timeline, including:

- Video recordings
- Audio recordings
- Investigator notes
- EMF readings
- Environmental sensor data
- Event markers

Users will be able to select a point on the timeline and immediately view all evidence associated with that moment.

## Example User Experience

An investigator uploads all evidence from an investigation.

Project Spector automatically synchronizes timestamps and generates a unified timeline.

The investigator selects 10:43:22 PM on the timeline and immediately sees:

- Camera footage from all active cameras
- Audio recordings from all active recorders
- Investigator notes
- Sensor readings
- Tagged events

This eliminates the need to manually compare multiple devices and recordings.

## Founder Insight #004

Project Spector does not create evidence.

Project Spector helps investigators find and understand evidence faster.

## MVP Focus

Version 1 will focus on:

- Case creation
- Evidence uploads
- Timestamp synchronization
- Unified timeline view
- Event markers
- Investigation notes

Artificial intelligence, automated anomaly detection, and hardware integrations will be considered in future releases after the core workflow has been validated.
