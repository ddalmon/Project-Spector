# Founders Meeting 005

Date: August 17, 2026

## Topic

Defining the Core User Experience and MVP Workflow

## Discussion

The team discussed how paranormal investigators and production crews should interact with Project Spector.

A key goal identified was minimizing the amount of manual organization required after an investigation.

Current workflows often require investigators to manually sort files, compare timestamps, and review multiple sources of evidence independently.

Project Spector will focus on automating this process.

## Decision #001

Users should be able to import all investigation evidence into Project Spector at one time.

The platform will automatically organize and categorize imported evidence whenever possible.

## Decision #002

Project Spector will use a unified timeline as the primary method of reviewing investigation data.

Evidence sources will be displayed as parallel tracks on a single chronological timeline.

## Timeline Tracks

Examples of supported timeline tracks include:

- Video recordings
- Audio recordings
- Investigator notes
- EMF readings
- Temperature readings
- Environmental sensor data
- Event markers

Additional evidence types may be added in future releases.

## Core User Workflow

1. Create a case.
2. Import investigation evidence.
3. Project Spector automatically processes files.
4. Evidence is categorized and organized.
5. Timeline tracks are generated.
6. Users review events from a unified timeline.

## Example User Experience

An investigator imports all evidence from a completed investigation.

Project Spector automatically:

- Reads available timestamps
- Categorizes evidence types
- Creates timeline tracks
- Places evidence on a synchronized investigation timeline

The investigator can then select a specific moment in time and immediately review all evidence associated with that event.

## Founder Insight #005

Project Spector should require as little manual evidence organization as possible.

Users should import evidence once and allow the platform to automatically organize, categorize, and map investigation data to a unified timeline.

## Design Principle

Import once. Spector organizes everything.

## MVP Features

- Case creation
- Evidence imports
- Automatic categorization
- Timestamp extraction
- Unified timeline
- Event markers
