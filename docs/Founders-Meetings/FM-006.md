# Founders Meeting 006

Date: August 17, 2026

## Topic

Evidence Catalog Architecture

## Discussion

The team discussed how imported evidence should be managed within Project Spector.

Initially, imported evidence was scanned and displayed to the user. However, this approach does not provide a long-term structure for timeline generation, event correlation, or future analysis.

A dedicated evidence catalog was identified as the foundation of the platform.

## Decision #001

Project Spector will create an evidence catalog for each investigation.

Imported evidence will be converted into structured evidence records and stored within the case.

## Evidence Record Structure

Each evidence item should contain:

- File name
- Evidence type
- File path
- Timestamp information
- Metadata (future)
- Event markers (future)

Example:

{
    "name": "camera1.mp4",
    "type": "VIDEO",
    "path": "test_evidence/camera1.mp4"
}

## Founder Insight #006

The evidence catalog will serve as the source of truth for an investigation.

Timelines, reports, analytics, and future AI features will all operate from the evidence catalog rather than directly from imported files.

## Future Benefits

- Timeline generation
- Evidence filtering
- Event correlation
- AI analysis
- Report generation
- Hardware integrations
